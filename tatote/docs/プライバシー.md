# タトて プライバシーポリシー

更新日：2026年8月5日

タトては、会社の同僚へ「外へ行く」合図を送るためのiPhone・Apple Watchアプリです。本ポリシーは、TestFlight版を含むタトての情報の取扱いを定めます。

## 取得する情報

- Appleでサインインから受け取る利用者識別子と、利用者がアプリに入力する表示名
- 招待、承認済みの友達関係、受信停止期限
- 最後にタトてを利用した時刻。承認済みの友達に対してのみ「オンライン」または「最終利用」として表示します
- タトの送受信の記録。日時、相手、送信か受信かの別のみを保存し、本人の「タトログ」にだけ表示します
- 通知配送に必要なApple Push Notification serviceの端末トークン
- 重複送信防止に必要な要求ID、送信者と受信者の内部ID、処理状態（最大24時間）
- 要求ID、利用者に対応する削除キー、結果コード、処理時間、再試行回数を含む診断情報
- リワード広告の表示・完了確認に必要な広告イベント、端末情報、広告識別子（端末設定で許可される場合）

位置情報、ヘルスケア情報、連絡先、音声は取得しません。タトてにメッセージ送信機能はないため、本文やコメントは存在せず保存もしません。診断情報に表示名や通知本文を保存しません。

## 利用目的

取得した情報は、本人確認、友達の招待と承認、通知の配送、連打制限、不具合調査、セキュリティ維持、アカウント削除、利用者が選択したリワード広告の表示と送信回数回復のために使用します。個人情報を第三者へ販売しません。

## 保存期間と削除

重複送信防止情報は作成から24時間以内、診断情報は7日以内、タトログは365日以内に削除します。アカウント情報、友達関係、端末情報は、アプリ内の「設定」からアカウントを削除した時点で削除します。退会する利用者に関連する未削除の情報も同時に削除します。本TestFlight版でApple Accountとの連携も解除する場合は、削除後にiPhoneの設定にある「Appleでサインイン」からタトてを選び、「使用を停止」を押してください。

## 外部サービス

認証にはAppleでサインイン、通知配送にはApple Push Notification service、利用者が選択したリワード広告にはGoogle Mobile Adsを使用します。各サービス提供者のプライバシーポリシーが適用されます。広告はiPhoneのメインアプリだけに表示し、Apple Watch、ウィジェット、通知には表示しません。

## 安全管理

通信はTLSで暗号化します。通知送信用の秘密鍵はアプリに含めず、通知サーバーだけで管理します。アクセストークンと端末トークンは目的に必要な範囲に限定して扱います。
