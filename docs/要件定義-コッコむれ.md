## 1. 思→鳴（設計書を作る中央側）

### 1-1. 0思 ─ 素材・要望・制約を未成形のまま列挙
- 要望：正論蒔宿より「久しぶりにこっこちゃんゲームを作ろう。畜学は更新されたのでしっかり読んで」。核は選択で **「群（むれ）＝よぶ／ちらす」**、器は **2D Canvas** に確定。
- 廿式の核：**縁＝衡＋ ∿ 衡−**（複数衡の並列振動・相互参照）。群れは**縁そのものを画面に出す**（設計学でいう林＝縁を、木＝一つの衡の中に描く）。**逆縁＝その ∿ を断つ力**＝群れを裂いて仲間を影に染める。
- 廿式の**赦（14）**：乱から循へ戻れる。実行は住から。許は不変、絶は対象外。→ 染まった仲間（乱）を、群れ（循の器）が包んで戻す＝**赦をメカニクスにする**（すみか 巻二・ついに・二「規則はそのままメカニクスにする」の継承）。
- 肥料学の制約（横展開は §12）：
  - 二人同時操作は作らない（kizuna・origami・ennami・yubikiri の4墓＝実証済みパターン）。**単独プレイ・親指1本**。
  - 「合体・吸収・消去」を作らない（koro・bubble・pop・link 系の既視の禁）。→ **何も消えない・何も融合しない**を一線にする。
  - 「つまらない・人気がない」8件。面白さの芯は**別解の多さ（創発）**（思考学 巻二・なお・三）。正解手順を1本もスクリプトしない。
  - 「群れを運んで目的地へ届ける／作業させる」＝ピクミン・レミングス系の当たり判定骨格は**採らない**（肥料学 二十一・二十三＝表面の動詞でなく当たり判定の骨格で既視を見る）。本作の骨格は**包囲の維持**であって運搬・撃破ではない。
- 技術の前提：Canvas2D（技術学 巻四②「2Dで足りる動詞なら2D」）。kagefumi（2D・60秒・逆縁・ランキング）の共有臓器をそのまま継げる。

### 1-2. 一言でこのゲーム（核の確定）
**夜明け前の島。指をおくと、こっこの群れがその周りに一つの輪をつくる。逆縁に染められた仲間（黒こっこ）は輪のいちばん薄いすきまへ逃げる。すきまを塞ぎ、輪の中に捉えつづけると、染めが落ちて仲間に戻る（＝赦）。だが逆縁のおおかげが突進してきて、密集した羽ほど多く染めていく。攻め（寄せて囲む）と守り（散らしてかわす）が、押す／離すという一つの指の中にある。60秒で夜が明け、つれもどした縁の数だけ光が空へ昇る。**

- **中心動詞＝よぶ／ちらす**。押している間＝よぶ（輪が縮んで濃くなる）、離している間＝ちらす（輪がゆるんで広がる）。**一つの入力の時間軸に深さを入れる**（gp2 巻二・続々・三の継承）。
- **既視感の回避（壱・最重要／禁止事項）**：群れに**運ばせない・働かせない・戦わせない・吸収させない**。群れは対象に触れて仕事をするユニットの集まりではなく、**形（輪）そのものが唯一のリソース**。何も消えず、何も融合せず、誰も倒れない。倒すのでなく**包んで戻す**（六＝敵は逆縁のみ／五＝親子の的）。
- **別解の多さ（創発）の構造的保証**：群れは boids（分離・整列・結合）＋指への引力／反発＋慣性で動き、黒こっこは包囲の薄いセクタへ逃げる。地形（岩・木立・水たまり）が輪の形を変える。**「この順で囲め」という正解を1本も書かない。** 岩へ追い込む／木立で足を鈍らせる／慣性で弧を振り回す／おおかげを囮に使う、はすべてプレイヤーの発見に委ねる。

- **③ 外部依存の切り分け（応でしか決まらない値は前提化。思へ戻さない）**：

## 2. 示式・十項（順序固定・省略不可）

### 2-1目的（応の指定）
**「指1本で群れの輪をつくり、逆縁に染められた仲間を包んでつれもどす」60秒のブラウザゲーム（1ファイル自己完結HTML＋Canvas2D＋WebAudio）が `/mure/` に実体化し、世界ランキング `rankings/mure` に繋がること。**

### 2-2幅（制約と外部前提・破れた場合の帰結）
- 1ファイル自己完結HTML。外部依存は世界ランキング（Firebase相乗り）のみ。破れ（外部エンジンが要る）→ **絶**（一器に納むの禁＝mori2 の死因）。

- 時間延長・無限モード・運の抽選を入れない。破れ → **絶**（弐・gp2 の教訓）。
- 何も消えない・何も融合しない・誰も倒れない。破れ → **絶**（壱＝koro/bubble/pop 系の骨格に落ちる）。
- 群れの手触り係数は §3 の初期値を**前提**とし、§13 M2 の手触りゲートで確定。破れ → **赦の経路**（係数調整のみ。システムを積まない）。
- 世界ランキングの実到達確認は環境制約で不能。破れ → **赦の経路**（正直に線を引いて出荷）。
- 期日：本周回のうちにPR作成まで。マージは正論蒔宿が押す（自分で押さない）。

### 2-3許（合格条件・実行者によらず判定可能な文。定め手＝正論蒔宿、判定の担い手＝実装者の検証）
**全必須。**（1）〜（8）が全て実測で真になること。
1. 実ポインタのドラッグで群れが指を追い、押している間に輪の半径が縮む（`state().ringR` が減少する）。
2. 黒こっこを輪の中心付近に捉えると `surroundOf(i)` が 0.75 以上になり、ゲージ満了で黒こっこが仲間に戻って `state().flock` が +1、`state().backs` が +1 される。
3. 黒こっこは包囲の薄いセクタ方向へ逃げる（包囲率が下がる向きに動く）。
4. おおかげの突進で `state().flock` が減り、`state().blacks` が増える。
5. `state().flock` は常に 4 以上。
6. `state().t` が 60 に達すると ending へ入り、over まで到達して結果が表示される。
7. 60秒の通しプレイで `pageerror` がゼロ。

## 4. 入力（一つの指の中に深さ）

- **押している間＝よぶ**：輪が縮む（濃くなる）→ 包囲が成立しやすい。ただしおおかげの一撃で多く染まる。
- **離している間＝ちらす**：輪が広がる（薄くなる）→ 包囲は成立しにくいが、突進で染まりにくい。
- 指の点は押していない間も**最後の位置に残る**（群れは緩く漂う）。
- PC：マウス左ボタン＝よぶ、矢印キー／WASD＝指の点の移動（押下扱い）。
- 禁止：二本指・同時入力・長押しメニュー・権限の要る入力（ジャイロ・マイク）。

## 5. 逆縁（六・敵は逆縁のみ）

- 敵は **おおかげ**（群れの ∿ を断つ力）と、**黒こっこ**（染められた仲間＝自分の影）だけ。他プレイヤー・親・子を敵にしない。
- 黒こっこは**攻撃してこない**。逃げるだけ。プレイヤーの点は減らさない（罰は霧）。
- おおかげは**倒せない**。かわすか、囮に使うか、耐えるだけ。おおかげに触れても**こっこは死なない**（染まって黒こっこ側へ移るだけ＝つれもどせる）。
- 群れが 4羽以下のときは**染まらない**（縁を完全には断たせない）。

## 6. 60秒の構造（弐・焔の形／参・終を售る）

| 時刻 | 出来事 |
|---|---|
| 0〜3秒 | 「よんで、つつんで、つれもどそう」READY。空は藍。 |
| 3〜11秒 | 黒こっこ2体。包囲の手触りを覚える時間。 |
| 11秒〜 | おおかげ初来。以後 間隔が縮む。黒こっこが9秒ごとに増える。 |
| 45〜60秒 | 空が白みはじめる（東の色が上がる）。密度は最大。 |
| 60秒 | **夜明け**。全ての動きが止まり、**1.2秒の無音**。つれもどした縁の数だけ光が一つずつ空へ昇り、和音が鳴る（祝福であって罰でない）。 |

- 結果画面：SCORE／つれもどした縁／さいだいコンボ／ベスト更新／ランキング登録。
- **無限モード・コンティニュー・時間延長は作らない。**

## 7. 技術（技術学 巻三の型に従う）

- Canvas2D 単一コンテキスト。`devicePixelRatio`（上限2）で実ピクセルを合わせる。
- 群れは配列＋毎フレーム全走査。近傍探索は**空間ハッシュ（セル 90u）**で O(N)（48羽＋黒6体なら素朴走査でも足りるが、羽ばたき粒子と合わせるためグリッドを持つ）。
- 音は WebAudio 合成のみ（矩形波・三角波・ノイズ）。**群れの羽音は羽数に比例**したノイズの重ね（smash 巻二・続々々々・九「既存プリミティブを重ねて厚みを作る」の継承）。
- こっこ＝`/chikumo.svg` を `new Image()` で読み込み `drawImage`。黒こっこ＝オフスクリーンcanvasに `source-atop` で暗色を乗せたティント版（kagefumi と同じ `buildBlack()` 方式／標準学 巻二＝品種を描き変えない）。
- 地形・道具は**絵文字**で描く（標準学 巻一）。独自アセットを足さない。
- localStorage：ベスト（`coccoMureBest`）・ミュート・名前・国旗・uid。
- Firebase：`rankings/mure` に相乗り（新規DB不要）。

## 8. 画面（見た目の細部は実装者の裁量）

- 夜明け前の藍→薄明のグラデ。星がまばら。地面は暗い草原、草の点描。
- 群れのこっこは白く光り、羽ばたきの粒子を落とす。輪が濃いほど地面に淡い光の環が出る。
- 黒こっこは暗い紫の靄をまとう。包囲ゲージは黒こっこの足元に**円弧**で出す（埋まったセクタが光る＝どこに穴があるか一目で分かる）。
- おおかげは画面外から伸びる大きな影。予兆で地面が暗くなる。
- 終端：光が一つずつ昇る。文字は最小限。

## 14. 検証（合格条件・実測の手順）

1. **中心動詞を一行目に置く**：実 `page.mouse.down()`＋`move` で黒こっこを輪に捉え、`surroundOf(0)` が 0.75 以上へ上がり、`backs` が 0→1、`flock` が +1 になることを実測。
2. 逃走：包囲率が高い状態で黒こっこの移動方向が**空きセクタ方向**であることを数値で確認。
3. 逆縁：`shadowNow()` で突進を強制発火し、`flock` が減り `blacks` が増えることを実測。群れ4羽で染まらないことも実測。
4. 下限・終端：`setT(59)` → over まで通す。結果画面の数値が state と一致。
5. 実ジェスチャ検証（おりづる 巻二・またまた・四／シン島 巻二・さらに・四の継承）：フック直叩きだけで合格としない。
6. rAF 凍結対策：`step(dt,n)` でクロックを決定的に進める。サブテスト間で押下状態と輪の半径を明示的にリセットする（ゆびきり 巻二・そして・五＝ハーネスの前提汚染）。
7. スクリーンショット目視：タイトル／包囲中（円弧ゲージ）／突進中／夜明け。
8. `node --check` を全インライン `<script>` に。
9. `--disable-webgl` 相当の特別な配慮は不要（Canvas2Dのみ）。ただし画像 `/chikumo.svg` の読み込み失敗時に**落ちない**こと（描かないだけ）を確認。
