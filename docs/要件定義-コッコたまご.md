# 要件定義：コッコたまご ─ だいて、はなして、つないでいく

> これは **蔵（正典）ではなく、新作こっこゲームを1本作るための作業用の要件定義書（設計書＝示）** です。
> 実装担当（軽量な頭）が、この1枚を読めば迷わず着手できるよう、数値・禁止事項・検証の合格条件まで書き切ります。
> 中心動詞は既存動詞一覧（そろえる・積む・叩く・合体・撃つ・避ける・つなぐ・斬る・ふっとばす・こぐ・走る・塗る・レースする・暮らす・折る・詰める/消す・かける・結ぶ/住まわせる・撒く/絡ませる・潮をよぶ・つりあわせる・影をふむ・打つ・よぶ/ちらす・うけあう）の**どれでもない**「**だく／はなす（抱く／手放す）**」。
>
> 起：丙午2026・文月三十。正論蒔宿より「シュミレータを利用して こっこちゃんのたまごっち作れますか？」＝**育成シミュレーターの依頼**。

## 0. 出荷条件チェックリスト（この項目が欠けたら出荷しない）

> しおさい2 巻二・続・一の教訓＝「見送ってよい項目と出荷条件を分けずに書いた設計側にも半分の責任がある」。ゆえに**先頭に置く**。
> 実装者の裁量に任せてよいのは**見た目の細部と音色だけ**。以下は全て出荷条件。

- [ ] S1 たまごは、**指で巣をつくって押している間だけ**あたたまり、かえる（＝だく）。
- [ ] S2 生まれたこっこは自分で歩き、**巣から離れているほど育ちが速い**（＝はなす）。指を離している間の距離が育ちになる。
- [ ] S3 離れつづけると**温**が下がる。0になると**ちぢむ**（その段の育ちだけ0に戻る。死なない・点は減らない＝罰は霧）。
- [ ] S4 段は 🥚たまご → ひな → こっこ → おや の4段。**おやが育ちきると光になり、たまごを残す＝継**（次の代がその場から始まる）。
- [ ] S5 逆縁＝**ブラックこっこ（そのこっこ自身の影）**は、こっこを引き寄せて育ちを止め、温を早く奪う。**倒せない・消せない**。段が上がる瞬間の光で**はれる**（散るだけ・6秒後にまた来る）。押している間、巣の光の中には入れない。
- [ ] S6 60秒で必ず終わる。終端は夜明けの**祝福**（1.2秒の無音 → 継いだ代の数だけ光が昇る → 和音）。
- [ ] S7 世界ランキング `rankings/tamago` に接続（既存作と同一パターン）。
- [ ] S8 タイトル右下に🔄こっこ強制更新ボタン。音の番人（pagehide）。ミュート・全画面ボタン。
- [ ] S9 こっこの姿は公式 `/chikumo.svg`（段は**大きさだけ**で表す・描き起こさない）。影は同じSVGの**暗い乗算ティント**。たまご・地形・道具は**絵文字**。
- [ ] S10 1ファイル自己完結。`node --check` 通過＋ヘッドレス実プレイで pageerror ゼロ。
- [ ] S11 検証フック `window.__tamago`（state / step / setT / hold / warp / chickWarp / shadowNow / skipToEnd / startGame）。
- [ ] S12 トップ目録・sitemap.xml・sw.js（CACHE版上げ）・畜史エントリ。

## 1. 思→鳴（設計書を作る中央側）

### 1-1. 0思 ─ 素材・要望・制約を未成形のまま列挙

- 要望：正論蒔宿より「**シュミレータを利用して こっこちゃんのたまごっち作れますか？**」。＝**育成シミュレーター**（たまごっち型）の依頼。核（育てる）と器（2D Canvas）はここで確定。
- **依頼と掟の正面衝突が二つある**（思考学 巻一⑤「七相との衝突を先に解く」）：
  - **壱・既視の禁**：たまごっちは既存ジャンルそのもの。「メーターが減る→対応するアイコンを押す→回復する」という**当たり判定の骨格**は、肥料学 二十一（学習シリーズ8作＝提示→選択→正誤判定）・二十三（poko＝ランダムに出る的を押す）で二度死んだ骨格と同型。**皮（こっこの卵を育てる）は継ぐが、骨格は捨てる。**
  - **弐・焔の形**：たまごっちは**底なしの微温**（終わらない世話・放置で減るメーター）そのもので、七相がもっとも忌む形。しかも死んだ木 shima2（肥料学 十七）は「7日間の育成システム」を持つ作り込みの厚い木だったが「つまらない・人気がない」で終わっている。
  - 解の型は先例どおり：**掟は捨てない、ジャンルの方を曲げる**（思考学 巻一⑤／shima2「終わらない島ぐらし → 7日で必ず終わる」／smash「再現するのは文法であって皮ではない」）。
- 廿式の核：**13継＝五式が差分を伴い次の認へ遷移（1>0：次の0<1へ降りる）**。育成とは継そのもの。**縁＝衡＋∿衡−** を「育てる側（指＝巣）∿ 育つ側（こっこ）」に当て、**逆縁＝その ∿ を断つ力**＝こっこを巣から引き離し、育ちを止める影。
- **たまごっちの魂で残すもの**：①ひとつの命に付き合う②時間とともに姿が変わる③自分の手が要る。**捨てるもの**：①世話メニュー②放置で減るメーター管理③終わらないこと。
- 肥料学の制約（横展開は §12）：
  - 二人同時操作は作らない（kizuna・origami・ennami・yubikiri の4墓＝実証済みパターン）。**単独プレイ・親指1本**。
  - 「合体・吸収・消去」を作らない（koro・bubble・pop・link 系の既視の禁）。**何も融合せず、誰も倒れない。**
  - 「つまらない・人気がない」8件。面白さの芯は**別解の多さ（創発）**。正解手順を1本もスクリプトしない。
  - 運搬・作業・誘導（ピクミン・レミングス骨格）を採らない（むれ §1-1 の継承）。**こっこに命令はできない。**
- 技術の前提：Canvas2D（技術学 巻四②「2Dで足りる動詞なら2D」）。むれ・かげふみの共有臓器をそのまま継げる。

### 1-2. 一言でこのゲーム（核の確定）

**指を置いたところが「巣」になる。たまごは、押して抱いているあいだだけ あたたまってかえる。生まれたこっこは自分の足で歩きだし、── ここからが逆になる ── 巣から離れているほど速く育つ。けれど離れれば温は下がり、0になれば ちぢんでやり直し。影（そのこっこ自身の逆縁）は、こっこを引き寄せて育ちを止めにくる。ひな→こっこ→おや と育てきると、おやは光になってたまごを残す。そのたまごから次の代が始まる。60秒でいくつの代をつなげるか。**

- **中心動詞＝だく／はなす**。たまごの間は「抱く」ことが育て、生まれたあとは「離す」ことが育てになる。**同じ指の同じ操作の意味が、段で反転する**のがこの木の核。
- **既視感の回避（壱・最重要／禁止事項）**：世話メニューを作らない。えさ・トイレ・薬・ミニゲームのアイコンを一つも置かない。減るメーターを押して戻す遊びにしない。**プレイヤーが触れるのは「巣の位置」と「押す／離す」だけ**で、こっこには命令できない（自分で歩く）。
- **別解の多さ（創発）の構造的保証**：こっこは自律（🦋ちょうを追う・寒くなれば自分で帰る）。巣は指と一緒に動かせる。地形（🌸はなばたけ＝育ちが速い／🌳こかげ＝温が減りにくい／💧みずたまり＝足が遅く温が減りやすい／🪨いわ＝通れない）が距離と温の計算を毎回変える。**「この順で育てろ」という正解を1本も書かない。** 巣を遠くに置いて危険な距離を稼ぐ／こかげを中継地にする／ちょうの行き先に合わせて巣を先回りさせる／影が来たら呼び戻して光でしのぐ、はすべて遊び手の発見に委ねる。

### 1-3. 鳴分岐 ─ 実装（木）へ降りる前の停止（掟・省略不可）

> 三つ（①成立判定文 ②反復の上限 ③通った経路）が揃うまで木へ降りない。揃わない状態は幅の未確定＝判定不能（鳴分岐 規則2）。

- **① 成立判定文（実装者によらず判定可能な一文）**：
  「**実ポインタ**（フック直叩きでない）の押下で たまごがかえり、指を離してこっこが巣から離れている間だけ育ちゲージが伸びて段が上がり、温が0になれば ちぢんで育ちだけが戻り（点は減らず・こっこは消えず）、おやまで育てきると光になってたまごが残り**代が1つ継がれる**ことが実測でき、影が接触している間は育ちが止まり段上がりの光で影がはれることも実測でき、60秒で夜明けの終端（継いだ代の提示）まで一連で到達できる」。これが言えたら本企画は成立。
- **② 反復の上限（幅の内）**：本設計書の思→鳴の反復は **3周まで**。3周で成立判定文が判定可能に固まらなければ打切り（前提化か探索型）。※ゲーム内の1ラウンド長（応の値）は §6 で60秒と別に定める。
- **③ 外部依存の切り分け（応でしか決まらない値は前提化。思へ戻さない）**：
  - **育ちと温の釣り合い係数**（GROW/WARM/距離の写像・こっこの足）は §3 に初期値を置くが、**手触りゲート（§13 M2・M3）を通すまで確定不能＝応依存**。→ **前提化**：破れ（60秒で1代も継げない／逆に楽すぎる）た場合の帰結は「M3 で停止し、許を再確認して係数だけ調整。システムは積まない」＝**赦の経路**（幅内）。むれ §16 の教訓（係数を勘で動かして悪化させた）に従い、**調整前に必ず実測（自動プレイで代数を数える）を取る**。
  - **世界ランキングの実到達**：サンドボックスから chikumo.jp・Firebase へ到達できない（既存作で実証済みの環境制約）。→ **前提化**：コードは既存作と同一パターンで書き、実登録の確認は**できないと正直に線を引く**（幅内。破れても絶ではない）。
- **通った経路の記録（差分）**：**思戻り1回 → 成立**。
  - 当初の核は「たまごっちの世話動詞を、正しいアイコンを押す代わりに**世界の中の物（🌾💧🎵）へ こっこを連れて行く**形に置き換える」案だった。しかしこれは**誘導＝運搬骨格**（ピクミン／レミングス）に落ち、むれ §1-1 で明示的に排除済みの骨格と重なると中央で判明。
  - そこで中央の新規素材として**廿式13（継）**を持ち込み、「世話をする」でなく「**離す**ことが育ちになる／育ちきった代は光になり次の代のたまごを残す」＝継そのものをメカニクスにする能動型へ核を寄せて再確定した（すみか「規則はそのままメカニクスにする」／むれ「赦をメカニクスにする」の同型）。打切りは無し。
  - この差分は §16 と `docs/鳴分岐.md`・`docs/示式.md` の事例へ還す。

判定：三つが揃った。**木（応）へ降りてよい。**

## 2. 示式・十項（順序固定・省略不可）

### 2-1目的（応の指定）
**「たまごを抱いてかえし、生まれたこっこを手放して育て、おやになった代から次の代へ継いでいく」60秒のブラウザゲーム（1ファイル自己完結HTML＋Canvas2D＋WebAudio）が `/tamago/` に実体化し、世界ランキング `rankings/tamago` に繋がること。**

### 2-2幅（制約と外部前提・破れた場合の帰結）
- 1ファイル自己完結HTML。外部依存は世界ランキング（Firebase相乗り）のみ。破れ（外部エンジンが要る）→ **絶**（一器に納むの禁＝mori2 の死因）。
- 世話メニュー（えさ・トイレ・薬などのアイコン選択）を一つも作らない。破れ → **絶**（壱＝たまごっちの骨格そのもの）。
- 放置で終わらない育成・セーブして続きから育てる形にしない。**1プレイ60秒で完結し、育ちは持ち越さない**（ベストスコアのみ保存）。破れ → **絶**（弐＝底なしの微温）。
- 二人同時入力を作らない。破れ → **絶**（kizuna 系4墓）。
- 時間延長・無限モード・運の抽選を入れない。破れ → **絶**（弐・gp2 の教訓）。
- こっこは死なない・消えない・倒れない。誰も倒さない。破れ → **絶**（参・五・六）。
- 育ちと温の係数は §3 の初期値を**前提**とし、§13 M3 の手触りゲートで確定。破れ → **赦の経路**（係数調整のみ。システムを積まない）。
- 世界ランキングの実到達確認は環境制約で不能。破れ → **赦の経路**（正直に線を引いて出荷）。
- 期日：本周回のうちにPR作成まで。マージは正論蒔宿が押す（自分で押さない）。

### 2-3許（合格条件・実行者によらず判定可能な文。定め手＝正論蒔宿、判定の担い手＝実装者の検証）
**全必須。**（1）〜（9）が全て実測で真になること。

1. 実ポインタの押下で巣ができ、たまごが巣の中にあるとき `state().hatch` が増加し、1.0 到達で `state().stage` が 0→1 になる。
2. 指を離してこっこが巣から離れている間だけ `state().grow` が増加し、巣のすぐそば（NEAR 以内）では増加しない。
3. `state().warm` が 0 になると `state().shrinks` が +1 され、`state().grow` が 0 に戻り、**`state().score` は減らず `state().stage` も下がらない**。
4. 段が 1→2→3 と上がり、stage3（おや）の育ち満了で `state().gens` が +1 され、stage が 0（たまご）に戻る。
5. 影がこっこに接触している間 `state().grow` が増えない。段が上がる瞬間、接触していた影が `hazed` 状態になる（`state().shadows` の生きている数が減る）。
6. 押している間、影は巣の半径 `NEST_R` の内側へ入れない（実測：影と指の距離が NEST_R を下回らない）。
7. `state().t` が 60 に達すると ending へ入り、over まで到達して結果が表示される。
8. 60秒の通しプレイで `pageerror` がゼロ。
9. `node --check` が全インライン `<script>` で通る。

### 2-4範囲（扱う／扱わない）
- **扱う**：`/tamago/index.html` の新規作成、トップ目録・`sitemap.xml`・`sw.js`（CACHE版上げ）への登録、畜史エントリ、蔵への還し（思考学・鳴分岐・示式、必要なら技術学）。
- **扱わない**：既存ゲームの改修、Firebase のDBルール変更（既存の `rankings/*` に相乗り＝新規DB不要）、3D／WebGL、多言語版、二人同時操作、ジャイロ・マイク等の権限が要る入力、セーブによる育成の持ち越し。

### 2-5構成（応に必要な要素）
1. 器：HTML1枚（音の番人 → meta/OGP → Firebase非同期ローダー → CSS → 画面DOM → 本体JS）。
2. 世界：朝もやの草地。地形＝🌸はなばたけ・🌳こかげ・💧みずたまり・🪨いわ・草の点描。
3. 巣：指の点。押している間は光の輪（NEST_R）。離しても最後の位置に残る。
4. こっこ：1体。段＝🥚たまご／ひな／こっこ／おや。生きている段は公式SVG（大きさだけが変わる）。
5. 逆縁：ブラックこっこ（同じSVGの暗い乗算ティント）。引き寄せ・育ち停止・温の追加消費。倒せない。
6. 🦋ちょう：1〜2匹。こっこが自分から追いかける（＝離れる理由）。
7. HUD：SCORE／◯代め／段の名／のこり時間／BEST。育ちと温はこっこの足元に2本の弧で出す。
8. 終端：夜明け（無音→光が昇る→和音）＋結果画面＋ランキング。
9. 共有臓器：🔄強制更新・音の番人・ミュート／全画面・国旗ピッカー・`rankings/tamago`・localStorage ベスト。
10. 検証フック `window.__tamago`。

## 3. 数値（実装者が発明してはいけない骨格。初期値は前提化＝§13 M3 で調整可）

画面短辺を `S=min(W,H)` とし、長さは `u=S/720` を掛けて解像度非依存にする。

| 項 | 値 |
|---|---|
| ラウンド長 DUR | **60秒**（固定・延長なし） |
| 巣の半径 NEST_R | **96u**（押している間だけ光る。影はここへ入れない） |
| たまごの孵り HATCH_SPD | 巣の中で押している間 **0.62/秒**（＝約1.6秒）／条件を外すと **0.10/秒**で戻る |
| 段 | 0=🥚たまご／1=ひな／2=こっこ／3=おや |
| 段ごとの育ち速度 GROW | ひな **0.40**／こっこ **0.32**／おや **0.26**（毎秒・farK=1のとき） |
| 距離の写像 farK | `clamp((d-NEAR)/(FAR-NEAR),0,1)`。NEAR=**NEST_R(96u)**、FAR=**330u** |
| 温 WARM | 上限1.0。巣の中で押している間 **+0.62/秒**、押さずに巣の中 **+0.18/秒** |
| 温の減り | **0.085＋0.075×farK**（毎秒）。🌳こかげ **×0.45**／💧みずたまり **×1.4**／影に触れている間 **×2.0** |
| ちぢむ（温0） | 1.2秒しゃがむ。**その段の育ちのみ0**／温を **0.5** に戻す／コンボ0／**段は下がらない・点は減らない・消えない** |
| こっこの足 | 基本 **92u/秒**／呼び戻し中（押している間）**×1.32**／💧の中 **×0.6**／ちぢみ中 **×0.7** |
| 地形の効き | 🌸はなばたけ：育ち **×1.35**／🌳こかげ：温の減り **×0.45**／💧みずたまり：足 **×0.6**・温の減り **×1.4**／🪨いわ：通れない |

| 影がはれる | 段が上がる瞬間、半径 **220u** の光の中の影が **はれる**（消滅でなく退場）。**6秒後**に画面外から戻る |
| 得点 | 段UP **100×コンボ**／代を継ぐ **500×コンボ**（コンボは段UPごとに+1・上限 **8**・ちぢむと0） |
| スコア上限 | 999999 |
| 🦋ちょう | **2匹**。こっこは **300u** 以内のちょうを追う（追われるとちょうは少し逃げる） |

**逓増difficultyの理由**（sorageri 巻二・さてまた・五の継承）：段が進むほど育ちは遅く（0.40→0.26）、影は増える（10秒・23秒・36秒）。どんなに上手い指でも代を重ねるほど維持が難しくなり、60秒の中で必ず密度が上がって終わる。

## 4. 入力（一つの指の中に深さ／段で意味が反転する）

- **押している間＝だく**：指の位置に巣の光。たまごはあたたまる。生まれたこっこは巣へ帰ってくる（温が満ちる・影が入れない）。**ただし育ちは止まる。**
- **離している間＝はなす**：こっこは自分で歩く。巣から離れているほど育ちが速い。**ただし温が減り、影が来る。**
- 巣（指の点）は押していない間も**最後の位置に残る**。押したまま動かせば巣ごと移動する。
- PC：マウス左ボタン＝だく、矢印キー／WASD＝巣の移動（押下扱い）。
- 禁止：二本指・同時入力・長押しメニュー・権限の要る入力（ジャイロ・マイク）。

## 5. 逆縁（六・敵は逆縁のみ）

- 敵は**ブラックこっこ（そのこっこ自身の影＝逆縁）**だけ。他プレイヤー・親・子を敵にしない。
- 影は**倒せない・消せない・攻撃してこない**。することは「引き寄せて、育ちを止める」だけ＝**縁の ∿ を断つ力**そのもの。
- 影を退けるのは攻撃でなく**育ちの光**（段が上がる瞬間）と**巣の光**（押している間）。**打ち返す操作を一つも作らない。**
- こっこは影に触れても死なない・染まらない・段は下がらない（罰は霧）。

## 6. 60秒の構造（弐・焔の形／参・終を售る）

| 時刻 | 出来事 |
|---|---|
| 0〜2.4秒 | 「たまごを だいて、あたためよう」READY。朝もやの草地。 |
| 2.4〜10秒 | 影なし。抱く→かえる→手放す、の反転を体で覚える時間。 |
| 10秒〜 | 影が初来。以後 13秒ごとに1体増える（最大3体）。 |
| 45〜60秒 | 東の空が白む。影は最大数。密度は最大。 |
| 60秒 | **夜明け**。全ての動きが止まり、**1.2秒の無音**。継いだ代の数だけ光が一つずつ空へ昇り、和音が鳴る（祝福であって罰でない）。 |

- 結果画面：SCORE／ついだ代／いちばん育った段／さいだいコンボ／ベスト更新／ランキング登録。
- **無限モード・コンティニュー・時間延長・セーブによる育成の持ち越しは作らない。**

## 7. 技術（技術学 巻三の型に従う）

- Canvas2D 単一コンテキスト。`devicePixelRatio`（上限2）で実ピクセルを合わせる。
- 実体数が少ない（こっこ1・影最大3・ちょう2・粒最大400）ので毎フレーム全走査で足りる。空間ハッシュは不要（技術学 巻四：必要な複雑さだけ）。
- 音は WebAudio 合成のみ（矩形波・三角波・ノイズ）。外部音源なし。
- こっこ＝`/chikumo.svg` を `new Image()` で読み込み `drawImage`。**段は大きさだけで表す**（描き起こさない＝標準学 巻二）。影＝オフスクリーンcanvasに `source-atop` で暗色を乗せたティント版（kagefumi・むれと同じ `buildBlack()` 方式）。
- たまご・地形・ちょうは**絵文字**で描く（標準学 巻一）。独自アセットを足さない。
- localStorage：ベスト（`coccoTamagoBest`）・ミュート・名前・国旗・uid。**育成の途中経過は保存しない**（弐）。
- Firebase：`rankings/tamago` に相乗り（新規DB不要）。

- こっこの足元に弧を2本：**内＝育ち（金）／外＝温（水色。減ると赤みへ）**。文字でなく弧で見せる。

- 前提化したもの：育ちと温の釣り合い係数（M3で確定）／ランキングの実到達（環境制約・正直に線を引く）。
