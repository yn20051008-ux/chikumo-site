## 2. 示式・十項（順序固定・省略不可）

### 2-1目的（応の指定）

**廿式がFXにおいて普遍的な式として成立するか否かに、判定可能な文で答える文書が存在すること。** 応＝本書および本書に含まれる対応表・反証テスト一覧。

### 2-2幅（制約と外部前提・破れた場合の帰結）

- 廿式との無矛盾。**廿式の語を再定義する改定は絶**（示式 §自己適用と同型）。同一構造での再開なし。
- 反復の上限（思→鳴）：5周、または定め手の打切り宣言。
- **反復の上限（検証そのもの）：反証テスト9本の判定完了／追加5周／定め手の打切り宣言のいずれか早いほう。**
  → **「正しいと証明されるまで」は上限として採らない。** 回数でも期限でもないため幅が未確定＝判定不能（鳴分岐 規則2）。加えて、結論を先に固定した反復は示式 原則8 が禁じる**許の無断補完**になる（通るまで回せば必ず通り、出た結論に情報が無い）。定め手からその形の指示があった場合も、本項の上限に置き換えて回す。
- **前提A：相場データが入手できる。**
  破れの帰結 → **探索型へ縮退**。成果物を「対応表＋反証テストの設計」と定めて成立させる。**幅内＝赦の経路。絶ではない。**
  **実績：前提Aは破れた**（403 CONNECT を実測）。縮退を実行し、出荷条件 S6 のみ未達で成立とした。
- **前提B：実行環境は使い捨てである。**
  破れの帰結 → git へ commit / push していないものは消える。**回避は赦の経路（push する）**。幅内。
- **前提C：定め手（正論蒔宿）が判定に応じられる。**
  破れの帰結 → 判定の担い手不在。中断（衡停止）とし、構造実体は維持して再開を待つ。

### 2-3許（合格条件・実行者によらず判定可能な文。定め手＝正論蒔宿、判定の担い手＝正論蒔宿）

全必須。ただし**許6のみ前提Aに従属**し、破れた場合は探索型の定めに置き換わる。

1. 廿式の二十語すべてにFXでの対応が割り当たり、**割り当てていない語がゼロ**である。
2. 各対応が判定可能な文で書かれている。書けない語は、**書けない理由が廿式の条文から**導かれている（「分からない」で済ませない）。
3. 対応の強さが段（A／B／C）で分類され、**各語がどの段かが一意に決まっている**。
4. 衡＝何かが本書の冒頭で一意に確定し、以後の記述と矛盾しない。
5. 廿式が禁じている事象が、**反証テストとして最低5本**列挙されている。
6. 反証テストのうちデータを要するものが実データで判定されている。**（前提A従属。破れた場合、「テストが判定可能な形で設計されている」に置き換える）**

## 4. 階層の縁（∿）の特定 ── 16〜18を判定可能にした鍵

15〜18 は全て同一形式「**X±が縁で循域安定**」で書かれている。よって各段を判定可能にするには、**その段の ∿ を一つ特定すれば足りる**。

| 階層 | 単位 | ∿（縁）＝二つのまま参照させる力 | 逆縁＝∿を断つ力 | 判定量 |
|---|---|---|---|---|
| 15家 | 一通貨ペアの板 | 買い ∿ 売り | 流動性の消滅 | スプレッド |
| 16衆 | 共通通貨で結ばれたペア群 | **三角裁定** | 一方のペアの取引停止 | クロスレート乖離 |
| 17国 | 通貨圏（＋中央銀行） | **カバー付き金利平価** | ドル調達難・資本規制 | **クロスカレンシー・ベーシス** |
| 18民 | 国際通貨体制 | 変動相場＋準備通貨の需給 | 体制の崩壊 | （単一数値に落ちない） |

> **裁定は ∿ の実装そのものである。** 廿式の ∿ は「二つのまま参照」（廿式 §構成式）。裁定は二つの市場を一つに融かさない ── 融ければ裁定は消え、参照が切れれば無限の利益になる。**二つのまま整合させ続ける力**が、FXには機構として実在する。

**階層が上がるごとに次元が一つ増える**：15家＝価格 → 16衆＝空間的整合（直物のみ） → 17国＝**時間**（先渡＝金利＝中央銀行がここで入る） → 18民＝体制。

### 4-1 判定文

- **16衆**：二つの通貨ペア市場が共通通貨を**逆の側**（基軸／決済）に持ち、両者から導かれるクロスレートと実際のクロスレートの乖離が**取引コスト（スプレッド＋手数料）の内**に収まっているとき、その組は衆として**循**にある。コストを超えて持続すれば**乱**。一方の取引が停止し三角が閉じなくなれば**絶**。
- **17国**：二つの通貨圏について、直物と先渡から導かれる**カバー付き金利平価の乖離＝クロスカレンシー・ベーシス**が所定幅の内にあるとき、国として**循**にある。幅を超えて持続すれば**乱**。通貨消滅・ペッグ崩壊で体制が成立しなくなれば**絶**。
- **18民**：**いずれの通貨も単独で価値を定めておらず**、基軸通貨（国＋）と非基軸通貨圏（国−）が相互参照して相場が成立しているとき、民として**循**にある。参照が断たれ複数の国が同時に相場を維持できなくなれば**乱**。体制が置き換わり同一構造で再開しなければ**絶**。

## 8. 差分（この設計書を書く周回で起きたこと）

- **主体の確定が最初の分岐点だった。** 「価格を衡とするか、トレーダーを衡とするか」で二十語のすべてが変わる。思鳴（内部）の有無で機械的に決まったが、これを後回しにしていたら全部書き直しだった。→ **森から降りよ（設計学）の実例。**
